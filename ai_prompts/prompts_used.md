# AI prompts used in this project

This file documents every Claude and ChatGPT prompt used to generate insights, summaries, and strategy recommendations in this project. It demonstrates a structured AI prompt engineering workflow.

---

## Prompt 1 — Project scoping
Used at: Start of project
Tool: Claude / ChatGPT
Purpose: Define business questions and domain-relevant hypotheses before touching the data.

## Prompt 2 — EDA insight interpretation
Used at: After exploratory analysis
Tool: Claude
Purpose: Convert raw statistical findings into an executive insight summary in banking language.

## Prompt 3 — Model result interpretation
Used at: After XGBoost training
Tool: Claude
Purpose: Explain AUC score and SHAP feature drivers in plain English for non-technical stakeholders.

## Prompt 4 — Retention strategy generation
Used at: After model interpretation
Tool: Claude
Purpose: Generate a 5-point retention strategy a Head of Retail Banking could action immediately.

## Prompt 5 — Python(MATPLOTLIB) executive summary
Used at: Dashboard design phase
Tool: Claude
Purpose: Write the 150-word narrative text box displayed on dashboard page 3.

## Prompt 6 — LinkedIn post
Used at: Portfolio publication
Tool: Claude
Purpose: Announce the project professionally on LinkedIn with data-driven highlights and a call to action.
